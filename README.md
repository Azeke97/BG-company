# BG Company

Nuxt 4 project: landing + service pages + mini-shop backend + mini admin.

## Quick Start

```bash
npm install
cp .env.example .env
npm run db:up
npm run db:migrate
npm run db:generate
npm run db:seed
npm run dev
```

## Main URLs

- Site: `http://localhost:3000` (or next free port)
- Admin: `http://localhost:3000/admin`

## Useful Commands

```bash
npm run tsc
npm run lint
npm run build
```
